# EER model

The EER diagram must match Alembic revision `0001_initial_schema` in
`backend/migrations/versions/0001_initial_schema.py`.

## Generate the schema export

Start PostgreSQL with Docker Compose, then run the migration:

```powershell
docker compose up -d postgres
cd backend
py -m alembic upgrade head
cd ..
docker compose exec postgres pg_dump --schema-only --no-owner -U $env:POSTGRES_USER $env:POSTGRES_DB > documentation/db/schema.sql
```

The PostgreSQL service was not available when this artifact was created, so
`schema.sql` is **UNVERIFIED** and must be generated by the developer.

## Create the DataGrip diagram

1. Open DataGrip and add a PostgreSQL data source for the Compose database.
2. Connect to the database and expand the target schema.
3. Right-click the schema and choose **Diagrams** then **Show Visualization**.
4. Include all four tables, foreign keys, unique keys, and cardinalities.
5. Confirm the diagram matches migration revision `0001_initial_schema`.
6. Export the diagram as PNG to `documentation/db/eer-model.png`.

The DataGrip PNG is **NOT MET** by this automated task; it requires the human
DataGrip workflow above.
